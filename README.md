# 蘑菇搭档 · 第九阶段试玩

公开试玩：https://mushroom-duo-first-gate.zishu41.chatgpt.site

两部手机直接打开，无需登录。一人创建房间，另一人输入6位房间码或打开邀请链接加入。首页默认选择「机关工厂」独立挑战，也可切换到「四关完整冒险」，同一房间连续游玩草地集合、地下接力、城堡会合和双人Boss；原三关冒险及各单关同样保留。手机横屏体验更好。

## 第九阶段：机关工厂（独立挑战）

首页默认选择机关工厂，也可在选关中切回原四关、三关或任意单关。工厂共8枚共享金币，单独记录最好成绩；原四关路线、32枚金币、已有成绩、成就和有效存档保留。旧本机手账会补充工厂统计，不清空原有记录。旧协议8房间升级时保留角色、位置、检查点和金币，旧页面需刷新使用协议9。

1. 贴住箱子侧面，按住互动＋方向推箱。沿滑轨推到黄色供能位，打开供能门。箱子无法穿过搭档；搭档站上箱子时箱体锁住，先跳下再继续推。
2. 借箱子跳上高台，在钥匙旁按住互动0.4秒取钥匙。回到地面，与搭档靠近，两人同时按住互动0.6秒传递。只能完成一次接力，不会在两人间反复弹回；取钥匙者不能直接开出口锁。
3. 两人穿过供能门，到中间旗帜会合，激活共享检查点。接力者带钥匙跳过裂隙，在出口锁旁按住互动0.6秒解锁，然后两人共同走到最右侧旗帜。
4. 持钥匙者倒下，钥匙留在安全地面；队友按住互动救援后，原持有角色取回。取钥匙者接力前退出，钥匙回到高台；接力后退出，补位的同色角色可取回钥匙，不会丢失或复制。
5. 顶部或场景下方“复位箱子与全队”将两人和箱子一起放回当前安全点，保留金币、时间和救援累计，计一次检查点重试及箱子复位。到检查点后复位或读档，箱子保持供能，钥匙归接力者，已解锁的出口保持解锁；检查点前读档从起点重做机关。复位会更新关卡代次，旧输入不能重放。
6. 工厂独立关沿用自动/手动存档、7天继续入口、本机手账、成绩复制和双方准备再来一次。工厂与原冒险各保留一份最新存档，首页分别显示继续入口；通关或更新其中一份，不会清除另一份。

## 试玩08.1修复

通过存档回到尚在30秒保留期内的离线角色时，会更新连接代次、清空旧按键并保留当前位置和纵向速度；延迟到达的旧跳跃和互动不会重新执行。连续重试保持同一房间、角色与连接代次。正常短断线、已在线的重复恢复和过期后的安全点恢复行为保持兼容。修复手机时钟慢于服务器时将有效存档误判为无效的问题，保留存档过期和格式检查。

慢网创建或加入期间打开玩法说明，连接完成后也会自动暂停；关闭后再恢复。如果连接在页面切后台后才完成，同样按暂离处理。

## 第八阶段：存档后继续冒险

每15秒、进入新关、激活检查点和中间关卡通关时自动保存；房间顶部书签按钮或下方“保存冒险”可手动保存。服务器保存权威进度，当前浏览器保留独立的恢复凭据，有效期为最近一次保存后的7天。凭据不放入邀请链接、公开房间快照或手机测试摘要。每个角色独立保存一份，后加入的玩家不能继承前一位玩家的存档入口。

30秒内短断线仍按原方式回到原房间、原位置；角色或房间失效后，首页“上次的冒险”卡片可用存档创建新房间，保留原红色或蓝色角色，复制新的邀请链接让搭档加入。从本关起点或已激活的检查点恢复，保留本趟编号、前面关卡成绩、金币、累计时间、救援和重试统计；恢复本身不增加重试次数。未到检查点的开关、升降台等机关需要重新配合，Boss从满血重开。已通关的中间关卡恢复为下一关起点；最终胜利记入手账并清除本机继续入口。

重复点击或网络丢失恢复响应会返回同一有效恢复房间及角色。恢复房间的角色再次超时或主动退出后，可重新从存档创建房间；已在恢复房间继续的存档不接受旧房间覆盖。服务器从已保存进度重建，不接受客户端提交任意金币、关卡或Boss血量。无需登录，不跨设备同步恢复入口；清理浏览器数据、更换浏览器或使用无痕会话会影响恢复。浏览器禁止存储时会提示，仍可正常联机。

## 第七阶段：完整冒险与本机手账

四关完整冒险共32枚共享金币。每关通关后，两人分别点准备才前往下一关；城堡会合后继续挑战Boss。所有关卡沿用同一房间、角色及冒险编号。最后展示四关金币、合计用时、救援和检查点重试统计，可复制成绩或同房间重新冒险。

最终通关后的「再来一趟」或单关「再战」也需要双方分别准备，让两人都能查看结算、保存本机成绩后再开始。队友暂离时等待恢复；旧一趟的延迟准备请求不会重置新冒险。

首页下方新增「本机冒险手账」，记录合作通关次数、四关最好用时、四关最高金币和最近的合作；展开可查看四关、三关和各单关独立的最好成绩。新通关会提示最好成绩与新成就。六项成就包括首次通关、完成四关、全金币、救援队友、不使用检查点重试完成连续冒险和击败Boss。

记录保存在当前浏览器，两部手机各自保存，不需要账号，也不做跨设备同步。观察到正在进行的冒险后，最终通关才记一次；中间关卡胜利不提前计入四关记录，重复快照、刷新、重连不重复计数。加入一个已经结束的房间不会新增记录。重新冒险产生新的编号，可计作下一次通关；检查点和当前关卡重试保留同一趟冒险编号。单关「再合作一次」产生新的编号。

手账保留最近15次完成记录，首页展示最近3次，并保留各模式累计和最好成绩。清除网站数据或更换浏览器会影响本机记录。浏览器无法保存时，游戏及成绩复制仍可使用，当前页面可临时显示本次成绩。手账不保存房间码和角色凭证。

## 第六阶段：双人 Boss 挑战

在选关中选择「新挑战 · 双人 Boss」，再创建房间。Boss可作为独立合作挑战关游玩，也已接入四关完整冒险的最后一关。

1. 两人经过左侧旗帜保存共享检查点。第一轮由任意一人在左侧引诱装置按住互动半秒，另一人到右侧高台待命。
2. 橙色预警落点锁定后有2.4秒准备时间，引诱者离开标记范围或跳起躲避震地。留在落点会扣心；护盾未破时碰撞Boss也会受伤。
3. 震地后出现8秒护盾破绽。由另一名玩家从高台起跳，从上方踩中Boss头顶。引诱者自己跳踩、从侧面碰撞或在护盾期间跳踩不能造成有效伤害。
4. 每次命中后交换职责：刚才跳踩的人回到引诱装置，刚才引诱的人去高台进攻。三次有效配合后打开右侧门，两人一起到旗帜通关。

画面顶部显示Boss生命、当前阶段、倒计时和双方分工。队友倒下时战斗暂停，可靠近按住互动1秒救援；全队倒下或按「全队回检查点」会恢复Boss三点生命和初始分工，金币与救援累计保留。重开本关会清空本关成绩。

断线保留期间Boss阶段、血量和角色分工随冒险一起暂停；恢复时清除旧输入。角色退出或座位过期会取消当次攻击，已造成的伤害保留，让新搭档从检查点重新配合。胜利后显示每次引诱/跳踩分工和共享成绩，可复制，也可在同房间再战。

## 第五阶段：手机和连接体验

手机页面适配窄屏、横屏、安全区域和动态可视高度。房间顶部显示联机状态，点击帮助可以查看最近网络往返耗时、恢复次数，并复制测试摘要。旋转屏幕、打开帮助、切换应用和恢复连接时会释放移动、跳跃和互动，避免旧按键重新执行。

打开帮助或邀请面板会暂停冒险，关闭后自动恢复。切后台或断网后角色最多保留30秒；收到暂离通知时立即暂停，否则在7秒未收到心跳后暂停。保留期间可刷新页面恢复原房间和原角色；重新打开页面时可选择“回到上次房间”。超时会释放座位，需要重新加入，同一房间的关卡、金币和检查点继续保留。30秒以服务端收到的最后一次心跳计算，倒计时只是提示。

新增跳跃、金币、踩怪、受伤、开关、检查点、救援和通关的原创合成音效。首次触碰或按键后才启用声音；可随时静音，并记住选择。切后台时停止声音，恢复后下一次操作重新启用。浏览器、系统静音和音量仍可能影响实际播放。

通关结算展示分钟和秒、三关共享金币、救援和重试次数，可复制合作成绩。复制失败时提供可选中的文本。

## 三关冒险与金币

1. 草地集合：学习跳跃、碰撞、踩怪，并分别站上同色踏板打开第一扇门。第一层平台的小旗是共享检查点。
2. 地下接力：供能、升降台、上方开路、裂隙、救援与共享检查点。
3. 城堡会合：高处和下路两条路线，移动平台、两个必须由不同玩家点亮的开关，以及会合桥梁。

每关8枚金币，全程24枚。金币由服务端根据真实接触判定，全队共享，同一枚只记一次；不要求收齐金币才能通关。移动平台的大时间间隔更新也检查沿途金币，避免弱网遗漏。检查点重试保留已收金币；重开本关会清空本关金币与成绩。

每关两人都到终点后，各自点击“准备前往”才进入下一关，不换房间、不换角色。延迟或重复的上一关请求不会再次切关。最后显示三关金币、用时、救援和检查点重试统计。“再来一趟三关冒险”会从第一关重置全部成绩；单关试玩结束只重开当前关。

## 合作接力

1. 一人站在左下黄色供能踏板上，另一人站稳单人升降台。供能者离开时升降台暂停；继续踩住即可恢复。到顶后，乘台者按向右走出。
2. 乘台者来到上方开关，按住「互动」半秒，打开下方捷径，让原来的供能者通过。双方轮流为彼此开路。
3. 触碰中间旗帜激活共享检查点。之后全队复位会保留已开的捷径，并从旗帜附近重新出发。
4. 跳过裂隙，到右侧分别踩住终点红、蓝踏板一秒，再共同走到旗帜完成关卡。

## 救援与失败恢复

城堡关先由一人沿阶梯到高处，按住互动半秒打开下方通道。另一人站稳移动平台，到岸后由服务端自动安置到安全岸边；再靠近对岸开关按住互动半秒，给高处队友架桥并打开终点门。两个开关不能由同一名玩家包办。两人会合后，在右侧小旗保存检查点，再一起到终点。

失足或生命耗尽会变成救援泡泡，泡泡会停在安全位置。活着的队友靠近并按住「互动」一秒即可救回，松手、走远或受伤会中断救援。救回后恢复三颗心，并短暂无敌。

全队倒下会在一秒后回到检查点；尚未激活检查点时回起点重做接力。联机状态下独自等待15秒也会回到安全点。

「全队回检查点」会让两人一起复位；手机横屏时位于顶部旗帜按钮，竖屏和电脑位于场景下方。城堡的检查点会保留已开的双开关与桥梁。「重开本关」会清空本关进度，三关冒险中会保留前面已完成关卡的成绩。

## 操作

左侧按钮移动，按住滑动可切换方向。右侧短按小跳、长按高跳；「互动」用于开关和救援。支持多指同时操作，松手、触控取消、切后台、转屏及打开帮助时都会释放按键。

电脑：方向键 / A、D移动，空格 / W / 上方向键跳跃，E键互动。基础训练保留实心平台、踩怪反弹、受伤无敌和安全复位。

联机用例支持 `TEST_ORIGIN`、`TEST_LATENCY_MS`、`TEST_JITTER_MS` 和 `TEST_DROP_RESPONSE=1`，可验证公网、延迟、抖动和响应丢失。三关联机用例也支持 `TEST_LEVEL=castle` 单独验证城堡。稳定输入重放误差只比较机关与敌人状态未改变的区间；队友踩怪引起的预测受伤撤销由专门回归用例覆盖。

重连用例使用实际等待验证30秒角色保留、7秒失联暂停、原身份恢复，以及旧连接输入和重复恢复隔离。连续测试默认至少15分钟，重复完成三关；可用 `TEST_SOAK_MS` 调整测试时长。自动化测试和浏览器尺寸检查不能代替两部实体手机验收：建议一部用Wi-Fi、一部用移动网络，连续合作15分钟，覆盖多指移动跳跃、切后台10秒后返回、断网恢复、转屏、开关救援、检查点及音效静音。

Boss接口用例通过两名玩家的真实输入帧完成三次交替跳踩及双人通关，支持相同弱网参数。设置 `TEST_BOSS_RECOVERY=1` 额外测试真实震地倒下、按住救援、检查点重试，以及预警中暂离/恢复和旧连接跳跃隔离。服务端不接受直接声明Boss扣血的请求。

四关联机用例会实际完成四张地图，在城堡进入Boss前验证暂停恢复和双方准备，并在两个独立的记录状态中验证最终成绩、序列化重载和重复快照去重。它模拟两部手机的数据保存流程，不能替代两部实体手机的浏览器持久化和触控验收。旧三关接口默认保持兼容；新界面创建四关模式时显式发送 `level: "journey"`。

## 同步实现

Canvas负责三张地图的画面。Worker与D1统一保存和判定房间、金币、机关、下一关准备和结算，客户端只发送带连续序号的固定时间步输入帧，并从服务端确认状态重放未确认输入。平台、救援和检查点复位由服务端判定；角色状态切换时更新输入代次，旧的移动、跳跃和互动不会在救回、下台或复位后重新执行。切关更新epoch并清空旧关输入。暂停及恢复更新connection并清空未确认输入，阻止延迟旧连接继续操作。数据库写入采用版本号并发校验，公开快照不包含角色凭证。
