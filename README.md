## 免费部署

使用 `render.yaml` 部署一个 `plan: free` 的 Docker Web Service，新加坡区域，健康检查 `/healthz`。不创建磁盘、数据库、后台 worker 或预览实例。启动命令来自 Dockerfile：`node dist/launch.mjs`。玩家不用登录 Render、GitHub 或 ChatGPT。

部署代码需先同步至用户控制的 GitHub 分支或子目录。当前 `ssjsjdjj/mushroom-duo` 仍保留原 Sites 源码，不要把它直接当成本发布版本部署。如果放在仓库子目录，需同步调整 Blueprint 的 Dockerfile 和构建上下文路径。

云端成功部署后，使用 Render 实际分配的 HTTPS 地址；不要根据服务名称猜测网址。保留该服务即可保留其分配的地址，服务运行仍受免费配额和平台政策约束。

## 免费限制

Render Free 在 15 分钟没有访问后休眠；再次打开大约需要一分钟。每月有 750 实例小时，并受流量和构建额度限制。没有支付方式时，超过额度应暂停服务或构建，保持零付费。

免费服务的本地文件在休眠、重启和重新部署后丢失，因此服务器房间和中途存档可能失效，需要新建房间；浏览器本机通关记录保留。本版本已在首页和存档卡片说明这些限制。存档内部七天期限只表示最长有效期，不能保证跨免费服务休眠保留。

这与“固定网址”不同：网址不依赖用户电脑开机；服务器仍可能休眠或因配额暂停。不能承诺永久免费政策不变或任意手机网络都可访问，发布后必须在受影响手机的普通浏览器中实测。

## 本地运行与检查

使用 Node.js 24：

```sh
npm ci
npm run build
npm test
npm start
```

默认端口 3000。`PORT` 设置端口，`HOST` 默认 `0.0.0.0`，`DUO_DATA_DIR` 指定 SQLite 目录。前端和 `/api/room` 同域，不依赖原 Sites 后台。游戏引擎和联机协议保持第九阶段版本。

已有验证包括 128 项检查、普通与弱网工厂双人全流程（各 8 金币）以及原四关冒险（32 金币）。本次仅增加免费托管配置和限制文案；云端 Linux Docker 构建、实际公开网址和手机访问均待账户连接后验证。镜像构建阶段会再次运行构建及 128 项检查。本机无 Docker。

## 发布顺序

1. 用户安装并连接 Render，首次使用完成免费账号注册。
2. 同步本发布版到受控 GitHub 分支或目录，创建唯一 Free Web Service。
3. 确认没有付费磁盘、数据库、套餐或支付方式；用量超限暂停。
4. 云端构建检查通过，取得实际 HTTPS 地址。
5. 无登录创建房间，两客户端加入，验证工厂接力、救援、检查点和通关。
6. 用户手机普通浏览器实测通过后分享新地址。
